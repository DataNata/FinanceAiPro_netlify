Подготовь сводный комментарий для финансового директора по всем компаниям группы за период. Данные по каждой компании уже рассчитаны: класс, балл, стоп-факторы, ключевые показатели и сигналы.

Верни JSON строго такой структуры:

{
  "summary": "2–3 предложения: общее состояние группы, сколько компаний в каждом классе, главная тенденция",
  "leaders": ["компании с лучшим состоянием и почему — 1 строка на компанию"],
  "attention": ["компании, требующие внимания: код, проблема (показатель, зона, число), что делать — 1 строка на компанию"],
  "group_risks": ["общие для нескольких компаний риски, 1–3 пункта"]
}

Используй только числа из данных. Сравнивай компании по коэффициентам и дням (все суммы в USD, но масштабы компаний разные).
