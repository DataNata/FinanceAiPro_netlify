Загрузить данные

Выберите оба файла или перетащите их сюда. Файлы проверяются и хранятся только в этом браузере (на сервер не отправляются); прежняя загрузка сохраняется — её можно вернуть.
Период — не меньше 15 месяцев подряд по каждому юрлицу, в ОПУ и в балансе, без пропущенных месяцев (квартал сравнивается с тем же кварталом прошлого года, долг / EBITDA — за 12 месяцев).
Формат файлов

Первая строка — заголовок: entity_code,company_name,year,month,code,value. Одна строка — юрлицо × месяц × статья. company_name можно не заполнять. code — код статьи из config\measures.toml, остальные статьи пропускаются. value — сумма в USD, расходы ОПУ со знаком «−». По каждому юрлицу — не меньше 15 месяцев подряд без пропусков. Разделитель , (числа с точкой) или ; (как сохраняет русский Excel, числа с запятой). Кодировка UTF-8 или Windows-1251. Лишние колонки (например, line_name из шаблона) пропускаются.

Нет файлов? Скачайте шаблон
В шаблоне — все нужные статьи с названиями (колонка line_name) на каждый месяц периода. Откройте его в Excel, впишите суммы в колонку value, сохраните как CSV и загрузите выше. Строки без суммы пропускаются. Выберите период не меньше 15 месяцев.
