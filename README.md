# FinanceAiPro — JavaScript-версия для Netlify

Помощник финансового аналитика: по CSV-файлам с ОПУ и балансом считает показатели финансового состояния по Методике,
ставит балл и класс A–D, находит стоп-факторы и сигналы, пишет заключение (LLM или шаблон) и выгружает его в Word и Excel.

Это перенос Python-проекта `FinanceAiPro_data JS` на JavaScript. Расчёт перенесён один к одному: тест сверяет каждое
юрлицо × период с Python-версией (баллы, классы, зоны и значения всех показателей, сигналы, тексты).

## Чем отличается от Python-версии

| | Python-версия | Эта версия |
|---|---|---|
| Где идёт расчёт | Python-сервер на компьютере | **В браузере** пользователя |
| Куда попадают загруженные CSV | Папка `data\csv` | **Только в браузер** (IndexedDB); на сервер не отправляются |
| Вход | Ключ в ссылке `?t=…` | **Код доступа** (`APP_PASSWORD`), сеанс 12 часов |
| LLM | Сервер вызывает LLM, ключ в `.env` | Функция Netlify `/api/llm`, ключ в переменных окружения Netlify |
| Word, Excel | python-docx, openpyxl | Собираются в браузере (`public/app/docx.js`, `xlsx.js`) |
| Пакетные отчёты (`run_assessment.cmd`), выгрузка для Power BI | Есть | Нет — только в Python-версии |

**Что уходит на сервер:** код доступа при входе и — по кнопке «Сформировать заключение» — посчитанные показатели юрлица
(те же, что Python-версия отправляла в LLM). Строки CSV не уходят никуда. Политика безопасности страницы
(`Content-Security-Policy`) запрещает ей обращаться к любым адресам, кроме своего сайта.

**Хранение — у каждого своё:** данные лежат в браузере того, кто их загрузил. Коллега на другом компьютере видит пустую
панель и загружает свои файлы. Удалить данные из браузера — «⬆ Загрузить данные» → «🗑 Удалить данные из браузера».

## Запуск на своём компьютере (без Netlify)

Нужен Node.js 22 или новее (https://nodejs.org). Интернет — только для LLM.

1. Дважды щёлкните `run.bat`. В первый раз создастся `.env` и откроется в Блокноте: впишите `APP_PASSWORD`
   (код доступа), `SESSION_SECRET` (любая длинная строка) и ключ LLM, сохраните и запустите `run.bat` снова.
2. Откроется http://127.0.0.1:8000 → введите код → «⬆ Загрузить данные» или пример «Алиса» / «ОАОМэри».

Без `APP_PASSWORD` сайт открывается без кода; с `LLM_PROVIDER=none` заключения пишутся по шаблону.

Публикация на Netlify — `docs/РАЗВЁРТЫВАНИЕ_NETLIFY.md`. Работа с панелью — `docs/ИНСТРУКЦИЯ.md`.

```
FinanceAiPro_netlify\
├─ public\                    САЙТ (то, что получает браузер)
│   ├─ index.html             панель: вид, фильтры, окно загрузки, шаблоны, заключение
│   ├─ login.html, login.js   страница входа по коду
│   ├─ favicon.svg
│   ├─ app\                   КОД РАСЧЁТА И ИНТЕРФЕЙСА (в браузере)
│   │   ├─ main.js            интерфейс: загрузка, отрисовка, заключения, выгрузки
│   │   ├─ csv.js             разбор и проверка CSV (ошибки по строкам, 15 месяцев подряд), шаблон
│   │   ├─ measures.js        коды статей → меры Методики
│   │   ├─ periods.js         месяц / квартал / год, LTM, прошлый год
│   │   ├─ indicators.js      формулы показателей, DuPont
│   │   ├─ zones.js, scoring.js, signals.js, quality.js   зоны, балл и класс, стоп-факторы, сигналы, контроль данных
│   │   ├─ analysis.js        всё по одному юрлицу за период
│   │   ├─ narrative.js       данные для LLM, разбор ответа, текст по шаблону
│   │   ├─ dataset.js         данные панели: все юрлица × периоды
│   │   ├─ reports.js         заключение и сводка (Word), расчёт (Excel)
│   │   ├─ docx.js, xlsx.js, zip.js   сборка файлов Word и Excel без библиотек
│   │   ├─ store.js           хранение в браузере (IndexedDB)
│   │   ├─ config.js, toml.js чтение настроек config\*.toml
│   │   └─ fmt.js             числа по-русски, округление как в Python
│   ├─ config\                копия config\*.toml для браузера — создаёт сборка, руками не править
│   └─ examples\alisa, mary   вымышленные компании для проверки (кнопки «Пример»)
│
├─ config\                    НАСТРОЙКИ (те же, что в Python-версии): settings, measures, indicators, scoring, signals, llm
├─ prompts\                   инструкции для LLM: system.md, conclusion.md, group.md
│
├─ lib\                       СЕРВЕР (функции Netlify и локальный сервер)
│   ├─ auth.mjs               вход по коду: подписанный cookie, «охранник» всех адресов
│   ├─ guards.mjs             блокировка перебора кода (5 попыток → 15 минут)
│   ├─ llm.mjs                вызов LLM потоком: Claude, Groq, OpenAI, Grok, Gemini, DeepSeek
│   ├─ handlers.mjs           /api/login, /api/logout, /api/info
│   └─ generated.mjs          промпты и config\llm.toml для сервера — создаёт сборка
│
├─ netlify\
│   ├─ edge-functions\auth.mjs  «охранник»: без входа — на страницу кода
│   ├─ edge-functions\llm.mjs   /api/llm — заключение потоком (дольше минуты)
│   └─ functions\login.mjs, logout.mjs, info.mjs
│
├─ scripts\build.mjs          сборка: config → public\config, промпты → lib\generated.mjs
├─ dev-server.mjs, run.bat    локальный запуск (повторяет Netlify)
├─ netlify.toml               настройки Netlify: сборка, папки, заголовки безопасности
├─ package.json               команды npm и зависимость @netlify/blobs (ставит Netlify)
├─ .env.example               образец переменных; .env — ваши ключи, никуда не загружается
├─ tests\                     автотесты (в сайт не входят)
│   ├─ parity.test.mjs        сверка с Python-версией по эталонам tests\golden\*.json

```

## Команды

| Что | Как |
|---|---|
| Локальный запуск | `run.bat` или `node dev-server.mjs` |
| Тесты | `node --test "tests/*.test.mjs"` (или `npm test`) |
| Сборка (её же делает Netlify) | `node scripts/build.mjs` |
| Пересоздать эталоны сверки после изменений в Python-версии | `"..\FinanceAiPro_data JS\.venv\Scripts\python" tests\make_golden.py` |

Настройки меняются в `config\*.toml` и `prompts\*.md` в корне — после правки перезапустить `run.bat` (или опубликовать заново).
Если меняются формулы — их нужно поменять и в Python-, и в JS-версии, пересоздать эталоны и прогнать тесты.
