# Публикация на Netlify

Сайт состоит из страниц (`public\`), функций (`netlify\functions\`) и Edge Functions (`netlify\edge-functions\`).
Функции нужны для входа по коду и для заключений LLM, поэтому **перетаскивание папки в окно Netlify (Netlify Drop)
не подойдёт** — оно публикует только страницы. Публикуйте через Netlify CLI (ниже) или через подключение репозитория.

## Перед публикацией

- **Что окажется в интернете:** страницы и код расчёта, настройки `config\*.toml`, промпты, вымышленные примеры
  «Алиса» и «ОАОМэри». Цифры компаний на сайт не попадают: пользователь загружает свои CSV в свой браузер.
  Папка `tests\` (в ней эталоны на цифрах 589 и 787) и файл `.env` в публикацию не входят.
- **Что уходит на серверы Netlify при работе:** код доступа при входе; по кнопке «Сформировать заключение» —
  посчитанные показатели юрлица, которые функция сразу передаёт в LLM (Groq, Claude…) и нигде не сохраняет.
  Это те же данные, что Python-версия отправляла в LLM со своего компьютера.
- **Код доступа:** 8 цифр подбираются медленно (5 ошибок — блокировка адреса на 15 минут), но длиннее надёжнее.
  Код и ключи хранятся только в переменных окружения Netlify — в коде сайта их нет.

## 1. Один раз: аккаунт и Netlify CLI

1. Зарегистрируйтесь на https://app.netlify.com.
2. Установите Node.js 22+ (https://nodejs.org), затем в командной строке:
   ```
   npm install -g netlify-cli
   netlify login
   ```
   Откроется браузер — подтвердите вход. Если корпоративная сеть не даёт ставить пакеты npm, сделайте эти шаги
   на другом компьютере (папку проекта можно скопировать целиком, кроме `.env`).

## 2. Один раз: создать сайт

В папке проекта (`FinanceAiPro_netlify`):

```
netlify sites:create --name financeai-<придумайте>
```

Команда сама свяжет папку с сайтом. Адрес сайта будет `https://financeai-<придумайте>.netlify.app`.

## 3. Один раз: переменные окружения

В Netlify: **Site configuration → Environment variables → Add a variable** (ключи отмечайте как «secret»).
Или из командной строки:

```
netlify env:set APP_PASSWORD 01061979
netlify env:set SESSION_SECRET <длинная случайная строка, например 64 символа>
netlify env:set LLM_PROVIDER groq
netlify env:set GROQ_API_KEY gsk_...
netlify env:set GROQ_MODEL openai/gpt-oss-120b
```

| Переменная | Обязательна | Что это |
|---|---|---|
| `APP_PASSWORD` | да | Код доступа к сайту. Пусто — сайт открыт всем (не делайте так на Netlify) |
| `SESSION_SECRET` | да | Подпись сеанса входа. Смена — все выходят и вводят код заново |
| `LLM_PROVIDER` | да | `groq`, `anthropic`, `openai`, `xai`, `gemini`, `deepseek` или `none` (без LLM, тексты по шаблону) |
| `<ПРОВАЙДЕР>_API_KEY`, `<ПРОВАЙДЕР>_MODEL` | для LLM | Ключ и модель выбранного провайдера (как в `.env.example`). Ollama на Netlify недоступна |

Изменили переменные — опубликуйте сайт заново (шаг 4), иначе функции их не увидят.

## 4. Публикация (и каждое обновление)

```
netlify deploy --build --prod
```

Netlify сам выполнит сборку (`node scripts/build.mjs`), поставит зависимость `@netlify/blobs` и опубликует сайт.
Без `--prod` получится пробная ссылка — удобно проверить перед заменой рабочего сайта.

## 5. Проверка

1. Откройте адрес сайта — должна появиться страница «Введите код доступа».
2. Неверный код → «Неверный код доступа»; верный → пустая панель «Данные не загружены».
3. Нажмите пример «Алиса» → карточка «Алиса», класс A, балл 93,8 (III квартал 2026).
4. «✨ Сформировать заключение» → через 30–90 секунд текст от LLM (если подключена).
5. «⎋ Выйти» → снова страница кода.

## Если что-то не так

| Что видно | Что делать |
|---|---|
| «LLM не настроена» на панели | Проверьте `LLM_PROVIDER`, ключ и модель в переменных окружения, опубликуйте заново |
| Вход не принимает верный код | Проверьте `APP_PASSWORD` (без пробелов), опубликуйте заново |
| «Слишком много неверных попыток» | Подождать 15 минут (блокировка по адресу) |
| «превышен лимит запросов» | Лимит бесплатного тарифа LLM; подождать, сколько написано |
| Ошибки функций | Netlify → Logs → Functions / Edge Functions |

Локально всё то же самое проверяется без Netlify: `run.bat` (см. `README.md`).
