# Как работать с панелью

## Вход

Откройте адрес сайта (или http://127.0.0.1:8000 при запуске `run.bat`) и введите код доступа. Сеанс действует 12 часов;
«⎋ Выйти» вверху справа — выйти сразу (на общем компьютере выходите после работы).

## Данные

Нужны два файла: **ОПУ** (`pl.csv`, обороты за месяц) и **баланс** (`bs.csv`, остатки на конец месяца).
Одна строка — юрлицо × месяц × статья, колонки `entity_code, company_name, year, month, code, value`.

- **Не меньше 15 месяцев подряд** по каждому юрлицу и в ОПУ, и в балансе, без пропущенных месяцев.
- Суммы в USD, расходы и убытки — со знаком «−». Разделитель `,` или `;`, кодировка UTF-8 или Windows-1251.
- Лишние колонки (например, `line_name` из шаблона) и строки без суммы пропускаются.

**Загрузить:** «⬆ Загрузить данные» → выберите оба файла (или перетащите) → «Загрузить». Ошибки покажутся списком:
файл, строка или юрлицо, причина — прежние данные при этом не меняются.

**Где хранятся:** только в этом браузере. На сервер файлы не отправляются; после перезагрузки страницы данные остаются.
В другом браузере или на другом компьютере панель пустая — там загружают свои файлы.
В окне загрузки: «↩ Вернуть прежние данные» (предыдущая загрузка) и «🗑 Удалить данные из браузера».

**Нет файлов — скачайте шаблон.** В окне загрузки блок «Нет файлов? Скачайте шаблон»: код юрлица, название, месяцы
(по умолчанию — последние 15) → «⬇ Шаблон ОПУ» и «⬇ Шаблон баланса». Откройте в Excel, впишите суммы в колонку `value`,
сохраните как CSV и загрузите.

**Посмотреть на примере:** кнопки «Алиса» и «ОАОМэри» — вымышленные компании.

**Страна в фильтре** берётся из `config\settings.toml` (раздел `[entities.countries]`). Юрлица, которых там нет, — «Без страны».
Добавить код — правка файла и новая публикация (или перезапуск `run.bat`).

## Заключения

- **«✨ Сформировать заключение»** — текст пишет LLM по посчитанным показателям (до 1–2 минут). В LLM уходят только
  показатели, не строки CSV. Текст сохраняется в браузере; если потом загрузить другие цифры, старый текст не показывается.
- **«✨ Для всех компаний периода»** — по очереди для всех карточек.
- **«📊 Сводка по группе»** — Word со сводкой и Excel с расчётом по всем компаниям выборки (в «Загрузки»).
- **«📄 Полное заключение (.docx)»** — заключение по Методике: итог, выводы, все показатели с зонами, DuPont, сигналы,
  рекомендации, контроль данных.
- **«⬇ Выгрузить в Word»**, **TXT**, **Копировать**, **Печать** — текст из окна заключения вместе с вашими правками.
